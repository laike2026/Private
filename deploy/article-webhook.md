# 第三方文章发布接口

POST `https://tiltrotator.com.cn/api/webhook/send_article`

请求类型：`application/x-www-form-urlencoded` 或 `application/json`。使用 HTTPS、不带 www 的正式域名，避免 POST 跳转。

| 参数 | 说明 |
|---|---|
| sign | 独立发布密钥，必填。密钥不保存在公开仓库中。 |
| class_id | `news` 新闻中心、`blog` 出海博客；兼容 `1`/`31` 对应新闻、`2` 对应博客；省略时默认博客。 |
| title | 必填，最多 140 字。 |
| content | 必填，正文最多 100000 字；支持常用安全 HTML 标签，也接受纯文本。 |
| author_id | 可选，`admin`、`1` 或空值显示为金品汇编辑部；其他值作为作者标识显示，最多 80 字。 |
| image_url | 可选，HTTP/HTTPS 封面地址；图片由浏览器加载，服务器不下载外部文件。 |

接口返回 HTTP 200 和 JSON：成功 `{"code":1,"msg":"发布成功"}`；失败 `{"code":0,"msg":"具体原因"}`。GET 不发布文章，返回提示使用 POST。

完整请求体上限 1MB；每个来源地址每分钟最多 30 次请求。正文中的脚本、事件属性、样式及危险链接会过滤。支持段落、二级至五级标题、列表、表格、引用、链接和图片。

成功后文章立即出现在相应栏目、后台和网站地图中。相同栏目、标题、正文、作者与封面重复提交会直接返回成功，不重复生成文章；修改内容后提交会生成新文章。

第三方工具建议填写：网站框架“自定义开发框架 Webhook”；域名 `https://tiltrotator.com.cn`；API_KEY 填单独交付的发布密钥；后台登录账号/author_id 填 `admin`；验证分类 ID 填 `blog`（如发布新闻则填 `news`）。若工具有独立“接口地址”，填写上面的完整 POST 地址。

公开仓库仅包含随机密钥的 SHA-256 校验摘要。服务器可通过 `ARTICLE_WEBHOOK_KEY_SHA256` 覆盖摘要以轮换或停用密钥；不要把原始密钥写入仓库、浏览器脚本、网址参数或日志。

联调请在隔离的 SITE_DATA_DIR 目录进行，避免向线上发布测试文章。API 发布的文章也可在原内容管理后台编辑、删除。
