# 腾讯云中国内地服务器部署说明

本项目以 GitHub 仓库保存源码，以腾讯云 Linux 服务器运行网站。GitHub 仓库位置不决定 ICP 备案；备案取决于实际接入的服务器、域名及企业主体。

## 部署前确认

- 腾讯云服务器类型、地域、公网 IP 和操作系统。
- 域名及其备案状态；未完成中国内地 ICP 备案前不要绑定域名公开提供服务。
- 服务器上现有的网站、Nginx 配置及端口占用，避免覆盖其他业务。
- 可用的 SSH 登录方式，及是否已经安装 Node.js 20+、Nginx。

## 应用配置

将仓库克隆到服务器的独立目录，例如 `/srv/jinpinhui/site`。进程使用以下环境变量：

```text
HOST=127.0.0.1
PORT=4173
SITE_URL=https://实际备案域名
ADMIN_SETUP_KEY=首次设置后台用的一次性随机密钥
```

应用只监听本机地址。公网由 Nginx 监听 80/443 并转发至 `127.0.0.1:4173`。不要将 4173 端口直接暴露在腾讯云安全组中。

`data/` 是持久数据目录：`content.json` 保存新闻和博客，`leads.json` 保存咨询，`auth.json` 保存后台密码摘要与会话密钥。`auth.json` 和 `leads.json` 已被 Git 忽略，不能提交仓库。部署更新时应保留并备份整个 `data/` 目录，不能用新仓库文件覆盖现有数据。

后台首次设置管理员密码的页面是 `/admin`。公网部署必须设置 `ADMIN_SETUP_KEY`，否则无法完成首次设置。首次设置需要同时输入部署密钥和管理员密码；完成后可移除环境变量中的部署密钥并重启服务。配置 HTTPS 和访问限制后再执行首次设置。

## 运行与反向代理

用 systemd 或服务器现有的进程管理器持续运行 `node server.mjs`，设置为开机启动。先在服务器本机请求 `http://127.0.0.1:4173/`，确认返回正常，再为 Nginx 配置反向代理。可参考同目录的配置示例；实际路径、域名、证书和服务用户须按服务器现状调整。

站点获得 ICP 备案号并完成正式上线后，启用 HTTPS、替换页脚备案占位文字、提交 `/sitemap.xml` 至搜索资源平台，并按要求办理公安联网备案。

## 更新

每次更新先备份 `data/`，再获取 GitHub 上的最新代码并重启应用。部署后检查首页、服务详情、新闻、博客、联系表单及后台。不要在服务器上直接编辑源码后执行强制覆盖。
